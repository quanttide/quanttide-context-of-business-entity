量潮课堂 Lite 付费方案 v2

一、定盘口径

任务书免费、提交免费；付费只买两样东西：参考材料、验收结论。

• 卖判读，不卖内容

• 卖「一次有记录的评审 + 可对照的参考」，不卖「通过」

• 个人买成长凭证，企业买真实任务与人才信号，两边共用同一套验收数据

Lite 因此更干净：它就是任务书的分发层与索引层，不是内容墙，也不该是。

二、产品三层

Lite · 免费

任务书全文（可下载、可公开转发、可被搜索收录）、看板、需求×验收筛选、理论/实践/我的分区、提交入口、评审维度公开。

个人 · 按次起步，后期收进订阅

参考材料解锁、验收（自动/人工）、复评申诉、认证、学习档案里的验收记录。

企业 · 席位 + 发包

私有任务池、发包管理、批量评审工时与 SLA、能力画像与人才匹配、沟通云/工作云沙箱席位。

个人线刻意不先卖年包：先按次/按包跑通，再把高频用户打包成订阅，顺序不能反。

三、免费 / 付费边界

免费五项：任务书全文、看板与筛选、提交入口、评审维度、公开讨论区。

付费五项：参考材料、平台验收、认证、学习档案中的验收记录、复评与申诉。

提交这一步绝不设卡。任务书免费带来的流量，全靠零门槛提交接住；漏斗是「看 → 做 → 交 → 想对照/要结论 → 付费」，卡在提交等于把漏斗掐断。

四、参考材料按验收类型拆三档

12 项里 8 项是开放验收，没有标准答案，统一对外叫「参考材料」，不叫答案：

• 精确 × 封闭（命令行试用）：参考操作路径 + 判定脚本说明，对应「issue 可复现」，近乎标准解

• 半精确 × 封闭（共识链 PoC）：提取范式 + 共识链标注样例（含悬而未决类）+ 通过指标

• 半开放 / 开放（其余 10 项）：往期优秀提交（脱敏）+ 评审维度 + 共识达成记录样例，本质是评分锚点

封闭类可对照自检，开放类可对照定位差距。既不撒谎，也不破坏「需求不全、没有标准解」的训练目标。

五、验收商品化：四个可计费单元

单元	单位	内容
自动验收	次	精确/封闭两项，即时出结论，低价引流
人工评审	任务包	1 次主评 + 1 轮追问 + 1 次复评，主力收入
认证	份	绑定可复现 issue / 共识达成记录，出可外链凭证
复评申诉	次	首次免费，后续小额；开放类争议走仲裁，不一人定案

评审维度随任务书免费公开，维度免费、判读收费。

定价锚点：单次人工评审 ≈ 真实评审工时成本 × 系数 + 结论可复用性溢价。用「一次开放验收的评审人力」+「学员拿到的可验证结论的用途」倒推，不用内容量定价。具体数字待阶段一实测后再定，方案里不写死。

六、个人线（完整旅程）

看任务书 → 免费做 → 免费提交 → 想对照就买参考包 / 自动验收 → 开放任务买人工评审 → 拿认证 → 写进学习档案 → 贡献抵扣下一轮。

权益清单：参考材料、验收结论、可外链认证、学习档案验收记录、复评申诉通道、贡献抵扣账户。

贡献抵扣（呼应页面里「把挡住你的交回来」）：issue 被复现、章程社区版被合入、宣传册建议被采纳 → 抵扣下次验收费或换认证加购。回流有正反馈，不是白干。

成果归属写死：PoC 结论、章程社区版、宣传册建议回流组织使用；学员保留署名权 + 作品集展示权。

七、企业线（完整）

企业买的不是课，是四件事：

• 发包：把真实低风险任务挂进任务池，正好对应页面里那些外部可见交付物（晋江发行、4399 发布、issue、ROADMAP）

• 席位：团队成员用 Lite/任务书 + 沟通云、工作云沙箱

• 验收产能：批量采购人工评审工时，约定 SLA 与复评规则

• 能力信号：基于「验收记录 + 可复现 issue + 共识达成记录」的能力画像与人才匹配

计价结构：发包费（按任务）+ 席位年费（按人）+ 评审工时包 + 匹配成功费。四项可单独买，也可叠成年度包。

结算与合规：成果归属在发包时约定；企业默认看不到学员未授权的原始提交；能力画像只输出验收结论与脱敏记录，不输出聊天原文、不输出未通过作品。

八、双边飞轮（v2 新增，也是最值钱的一处）

任务书免费公开 → 个人流量与提交 → 沉淀验收记录 → 企业看到真实能力信号 → 企业发包 / 买席位 → 产生更多真实任务 → 脱敏后的优秀提交反哺成个人侧「参考材料」 → 参考包越用越厚 → 回到个人。

意味着参考材料不用自己编，随运营自然积累；企业侧也不只是收钱，它在给个人侧供给内容。这是「任务书免费」能成立的结构性理由，不只是获客话术。

九、任务书要补的字段

每份任务书新增 6 项，付费规则才立得住：

验收档位（自动/人工）、参考材料解锁条件、评审维度、复评与申诉规则、成果归属与署名、贡献抵扣规则。

企业发包再加 3 项：发包方、脱敏范围、评审 SLA。

十、护栏

• 付费不绑定「通过」，购买页写清楚

• 开放类争议走复评/仲裁，不让单个导师定案

• 开放类参考材料不叫「答案」

• 归属、署名、作品集展示权写进任务书，不靠口头约定

• 企业侧数据授权与脱敏前置

• 「付费来给量潮干活」的观感，靠任务书免费 + 提交免费 + 贡献抵扣三层消解

十一、上线节奏

阶段一：个人侧先上「命令行试用 + 共识链 PoC」的参考包与自动验收。判定最干净、成本最低，专门测付费意愿。

阶段二：上两项半开放（晋江发行、4399 H5），把人工评审维度定下来；同期找 1–2 家企业做发包试点，验证飞轮前段。

阶段三：铺开 8 项开放验收的评审与认证，开放企业席位年费与匹配；个人侧把按次用户打包成订阅。

十二、盯这几个数

提交→付费转化率（漏斗核心）、自动验收与人工评审的毛利差、参考包解锁后的复购、企业发包数与席位续费、匹配成功率、贡献抵扣核销率（观感健康度）、申诉率（开放验收质量）。

十三、暂时不定

具体价格数字、认证是否外部互认、企业发包任务是否对外公开、订阅打包的档位划分——都等阶段一实测再定。
