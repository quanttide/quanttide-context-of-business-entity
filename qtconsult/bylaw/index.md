# 量潮咨询工作章程

第一条 总则

1.1 本章程适用于本公司提供的所有线上及线下企业咨询服务。

1.2 客户购买咨询服务的本质是购买专业时间与经验支持，而非获得任何形式的“结果保证”或“绝对解决方案”。

1.3 客户完成付款即视为已充分阅读、理解并同意本章程全部条款。

第二条 定价与计费

2.1 线上单次咨询按小时计费，标准为每小时人民币XXX元。不足三十分钟按半小时计，超出部分按比例累加。

2.2 线下单次咨询按半日制计费，标准为每半天人民币XXX元（不超过四小时）。差旅费用另议。

2.3 项目制深度咨询按整体项目报价，双方另行签署服务合同。

第三条 支付与退费

3.1 小时制及半日制咨询须在服务开始前全额预付。

3.2 项目制咨询须在启动前支付不低于总额百分之五十的定金。

3.3 服务一旦启动，所收费用概不退还。

3.4 客户如需取消或改期，须在约定时间前二十四小时通知我方。逾期通知的，视为已消费，费用不予退还。

3.5 因我方原因导致咨询无法正常进行的，全额退还已收费用或协商改期。

第四条 服务边界与预期管理

4.1 我方提供的服务内容包括专业视角分析、经验分享及策略建议，不构成对任何商业结果的承诺或保证。

4.2 单次咨询有其固有局限性，无法解决客户企业的全部问题。客户如需持续支持，可另行签约年度顾问服务。

4.3 客户须在咨询前提供具体的背景资料及待解决问题清单。因客户提供信息不实或不完整导致建议偏差的，我方不承担相应责任。

4.4 本服务的交付标准为：是否提供了专业分析框架、可行性策略建议及清晰的行动路径，而非“问题是否彻底解决”。

第五条 咨询流程

5.1 客户提出咨询意向后，双方进行不超过十五分钟的免费沟通，以确认需求匹配度。

5.2 需求匹配的，由我方向客户发送本章程，客户确认后完成付款。

5.3 付款完成后，双方协商确定具体咨询时间并开展服务。

5.4 咨询结束后，我方可根据客户需要提供简要书面纪要。

第六条 附则

6.1 本章程由本公司制定并保留最终解释权。

6.2 本章程将根据业务发展需要不定期修订，以最新版本为准。

6.3 本章程未尽事宜，参照双方另行签署的书面协议执行。
